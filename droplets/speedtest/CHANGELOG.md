# Changelog

## [1.0.0] - 2026-10-27

- First release: run Speedtest by Ookla from the shelf, with live speeds beside the notch.
- Asks you to accept Ookla's license and privacy policy once, before the first test.
- Measures with Apple's network test when Ookla's CLI isn't installed, and says so.
- Open the widget from Thunderstorm, where it shows the full result.
- Start and stop a test from a `droppy://droplet/speedtest/run` or `/stop` link.
